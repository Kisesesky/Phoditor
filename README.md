## 화면 개편 (2026-11-25)

예전 화면은 엑셀 칸을 격자로 늘어놓은 "뷰어"에 가까웠습니다. 이제 문서 편집 프로그램처럼 바뀌었습니다. 예전 화면 파일은 `_보관_20261125/ui_개편전_20261125/`에 있습니다.

- **시작 화면**: 종류(개수 표시) → 업체 카드에서 바로 시작.
- **편집 화면**: 위 도구 막대(블록 추가·아래에 추가·블록 삭제 / 반복값·글꼴·격자 / 내보내기), 왼쪽 사진 패널, 가운데 **쪽 보기**, 오른쪽 **속성 패널**, 아래 시트 탭 + 상태 막대(쪽 수·예상 용량·확대).
- **쪽 보기**(`pageview.js` + `sheetmodel.js`): 인쇄되는 쪽 그대로 그립니다. 용지·방향·여백·배율(쪽 맞춤)·인쇄 영역·반복 행·가운데 맞춤·수동 쪽 나누기·머리말/바닥글(쪽 번호, `{{현장명}}`)·실제 테두리(선 모양·색)·채우기(옛 색 번호표 포함)·로고 그림·글상자/도형·칸 안 줄바꿈. 열 너비는 기본 글꼴의 숫자 폭을 실제 글꼴로 재서 Excel과 같은 규칙으로 바꿉니다.
  - 빈 양식 21개의 전체 쪽 수가 Excel PDF와 20개 같습니다. 분양 롯데는 Excel이 갑지·간지를 저장된 배율(85%)로 찍어 오른쪽 장식선이 빈 쪽으로 넘쳐 7쪽이 되고, 앱은 5쪽으로 보입니다(양식 자체의 성질).
  - 머리말·바닥글 속 그림(&G, 대우 PRUGIO 로고 등)은 아직 화면에 안 보입니다. 내보낸 파일에는 그대로 있습니다.
- **속성 패널**: 고른 것에 따라 바뀝니다. 문서(현장명·문서 글꼴 바꾸기·양식 정보) / 블록(추가·삭제·반복값) / 칸(글꼴·크기·굵게) / 사진 자리(미리보기·자르기·원본·빼기·배치 1~4장).
- 사진을 빈 사진 영역에 끌어 놓으면 바로 1장 배치로 들어갑니다(배치는 속성 패널에서 바꿈). 이미 넣은 사진은 사진 패널에 "넣음 n"이 표시됩니다.
- 맥 제목 막대를 도구 막대와 합쳤습니다(`titleBarStyle: 'hiddenInset'`).

### 작업 저장·실행 취소·한꺼번에 채우기 (2026-11-25)
- **작업 저장·열기**: ⌘S 저장, ⇧⌘S 다른 이름으로, ⌘O 열기. 작업 파일 `.pbook`은 PLAN 주제 4대로 **JSON + 사진을 한 파일(zip)** 에 묶습니다(`project.json`, `photos/`, `edits/`). 다른 Mac에서 열어도 사진이 그대로 나옵니다. 열면 사진은 `userData/projects/`에 풀어 쓰고, 사진 폴더도 다시 엽니다. 정의서 버전이 다르면 알려 줍니다. 예전(JSON만) `.pbook`도 열립니다.
- **시작 화면 "최근 작업"**: 저장한 작업을 바로 엽니다.
- **자동 저장**: 고친 뒤 2.5초마다 `userData/autosave/current.json`에 저장합니다. 저장하지 않고 꺼졌으면 **앱을 열 때 묻지 않고 이어서 엽니다**(PLAN 주제 4).
- **닫을 때 확인**: 저장 안 한 변경이 있으면 저장 / 저장 안 함 / 취소를 묻습니다(창 닫기·⌘Q·양식 목록으로 나가기). 제목 옆에 "수정됨"이 표시됩니다.
- **실행 취소·다시 실행**: ⌘Z / ⇧⌘Z 또는 도구 막대 화살표. 칸 입력·사진 넣기/빼기/자르기/돌리기·블록 추가/삭제/이동/복제·시트 추가/삭제/이름·글꼴·자동 채우기·표 붙여넣기·목차 채우기를 60단계까지 되돌립니다. 입력 중인 칸 안에서는 글자 단위로 되돌립니다.
- **사진 자동 채우기**(도구 막대 [사진 채우기]): 왼쪽 사진을 이 시트의 빈 사진 자리에 차례대로 넣습니다. 순서(파일 이름·찍은 시간·패널 순서), 안 넣은 사진만/전부, 자리마다 1장/지금 배치대로, 선택한 블록부터/처음부터, 모자라면 블록 자동 추가.
- **블록 이동·복제**: 속성 패널의 ↑ 위로 / ↓ 아래로 / 복제(글자·사진 포함).
- **표 붙여넣기**(도구 막대 [표 붙여넣기]): 엑셀에서 복사한 목록을 붙이면 블록마다 차례로 칸을 채웁니다. 첫 줄이 제목(위치·품목 등)이면 열을 자동으로 맞추고, 열마다 넣을 칸을 바꿀 수 있습니다. 한 쪽에 항목이 2개인 양식은 두 줄씩 한 블록에 들어갑니다.
- **자동완성**: 칸에 입력할 때 같은 칸(위치·품목·업체명 등)에 예전에 적은 값이 목록으로 나옵니다(↓·Enter로 고르기). 앱을 껐다 켜도 기억합니다.
- **목차 자동 채우기**: 목차 시트 속성 패널. 머리글이 "구분·차례·품목"인 목차(준공 롯데 등)에 블록 시트 이름·번호·품목을 채웁니다. 다른 모양의 목차는 직접 입력합니다.
- **사진 패널**: [안 넣은 것만] 보기, 이름순/찍은 시간순(사진 속 촬영 날짜, 없으면 파일 수정 시각), 사진 위 ⤢로 크게 보기(←/→ 넘기기).
- **사진 돌리기**: 사진 자리 속성 패널 [↻ 돌리기] — 오른쪽으로 90°씩. 자르기와 함께 써도 항상 원본에서 다시 만들어 화질이 떨어지지 않습니다.

### 3순위 기능 (2026-11-25)
- **PDF로 내보내기**(도구 막대 [PDF], ⇧⌘E): 엑셀 파일을 만든 뒤 Mac Excel로 인쇄해 PDF를 만듭니다(엑셀 인쇄와 같은 결과). Mac Excel은 샌드박스 앱이라 Excel 자기 폴더(`~/Library/Containers/com.microsoft.Excel/Data/Phoditor-pdf/`) 안 임시 파일로 작업하고 끝나면 지웁니다. 처음 한 번은 macOS가 "Excel 제어 허용"을 묻습니다.
- **넘치는 글자 경고**: 입력한 글자가 칸보다 길면 칸에 빨간 표시, 상태 막대에 "넘치는 글자 n칸"(누르면 차례로 보여 줌). 칸 속성에서 **[칸에 맞게 글자 줄이기]** 를 켜면 화면에서도 줄여 보이고, 엑셀에는 "셀에 맞춤"(shrinkToFit)으로 들어갑니다.
- **반복값 표시**: 고치면 여러 블록이 같이 바뀌는 칸은 연보라 바탕 + ↻ 표시, 누르면 안내가 나옵니다.
- **사진 위 표시**: 사진 자리 [표시] 또는 속성 패널 [사진 위 표시…] — 화살표·네모·글상자, 색 7가지, 선 굵기, 글자 크기. 이동은 끌기, 글 고치기는 두 번 누르기, 지우기는 Delete. 내보낸 엑셀에는 **고칠 수 있는 도형**(화살표·네모·글상자)으로 들어갑니다.
- **지난 현장 복제**: 시작 화면 "최근 작업" 카드의 [복제] — 새 현장명을 넣으면 사진은 비우고(배치·블록 수·글자는 선택해서 남김) 표지·머리 행 현장명을 바꿔 새 작업으로 엽니다. 원래 작업 파일은 그대로입니다.

## 2단계 추가 기능

### A. 넣기 전 크롭 (Q7)
- 사진 패널(로컬 폴더·MYBOX 공통)에서 **[크롭]** 버튼 클릭 또는 **사진 더블클릭**으로 자유 비율 크롭 편집기를 엽니다.
- HEIC·WEBP·TIFF는 JPEG(품질 95)로 변환된 상태로, EXIF 회전이 있는 사진은 회전이 적용된 정방향으로 크롭 편집기에 표시됩니다.
- 크롭 편집기에는 긴 변 1600px 이하로 줄인 미리보기만 보내고, **[확인]** 시 메인 프로세스가 원본 해상도로 `sips` 크롭 후 **JPEG 품질 96**으로 인코딩합니다. 크롭본은 사진 패널에 별도 표시(`크롭` 배지)됩니다. 원본 파일은 수정되지 않습니다.
- 크롭본에는 **[원본으로 되돌리기]** 버튼이 제공됩니다. 이미 사진 자리에 넣은 크롭본이 있으면 확인 후 그 자리도 원본 사진으로 바꿉니다. **[취소]** 시 아무것도 생성되지 않습니다.
- 크롭본도 1단계와 동일하게 contain + 중앙 정렬 + 여유(`min(8px, 5%)`) 및 SHA-256 중복 제거가 적용됩니다.

### A-2. 넣은 뒤 크롭 (2026-11-25)
- 사진을 넣은 자리 오른쪽 아래 **[크롭]** 버튼 또는 **자리 더블클릭**으로 크롭 편집기를 엽니다. 확인하면 **그 자리만** 크롭본으로 바뀝니다(사진 패널·다른 자리는 그대로).
- 항상 원본 사진에서 다시 자르므로 여러 번 잘라도 화질이 떨어지지 않습니다. **[다시 크롭]**은 지난번 고른 영역에서 시작합니다.
- **[원본]** 버튼으로 그 자리를 자르기 전 사진으로 되돌립니다. 원본 파일은 수정되지 않습니다.

### 사진 크기 (2026-11-25)
- 사진 자리 미리보기는 240px 썸네일을 원래 크기로만 보여 줘서 자리에 비해 작게 보였습니다. 이제 긴 변 1200px 미리보기를 자리 크기에 맞춰 보여 줍니다.
- 내보낼 때도 자리보다 작은 사진(작은 원본·많이 자른 크롭본)을 키우지 않던 규칙을 바꿔, 비율을 지키며 자리에 꽉 맞춥니다(여유 `min(8px, 5%)`는 그대로). PLAN S17.

### 시트 이름 바꾸기 (2026-11-25)
- 아래 시트 탭(갑지·표지·목차·공간별전경·공용홀1층 …)을 **더블클릭**하면 이름을 바꿀 수 있습니다. Enter·다른 곳 클릭은 저장, Esc는 취소.
- Excel 규칙을 따릅니다: 31자 이하, `\ / ? * [ ] :` 불가, 앞뒤 `'` 불가, 같은 이름(대소문자 무시) 불가.
- 앱 안에서는 원래 시트 이름을 그대로 열쇠로 쓰고(쪽 번호·인쇄 설정·빈 양식 연결), 내보낼 때 마지막에 파일 안 이름을 바꿉니다. 시트 목록·인쇄 영역·다른 시트를 가리키는 수식·하이퍼링크·문서 속성까지 함께 바뀝니다(`sheetrename.js`, `node test-rename.js`).

### 미리보기 글꼴 (2026-11-25)
- 예전에는 미리보기 칸에 Excel 글꼴을 적용하지 않았습니다(모든 칸이 앱 기본 글꼴). 이제 칸마다 Excel 파일에 적힌 글꼴로 보여 줍니다.
- **앱에 넣은 무료 글꼴 10종**(`app/fonts/`, 약 42MB): 나눔고딕·나눔명조·나눔바른고딕·나눔스퀘어·나눔스퀘어라운드·마루 부리·Noto Sans KR·Spoqa Han Sans Neo·Pretendard·IBM Plex Sans KR. 출처·라이선스는 `fonts/LICENSES.md`.

### B. MYBOX 연동 (Q9 + 주제 5)
- **PAT 설정 방법**:
  1. MYBOX 웹 → **설정** → **계정 및 개인 액세스 토큰 관리** → **토큰 생성** (유효기간 30/60/90/180일, 생성 직후 1회만 표시되므로 즉시 복사)
  2. 앱 상단 **[MYBOX 설정]** 또는 MYBOX 탭의 **[설정]** 클릭 → PAT 붙여넣기 → **[저장]** (Electron `safeStorage`로 암호화 저장, 평문 저장·로그 출력 금지)
  3. **[연결 테스트]** 버튼으로 서버 응답 상태 코드와 연결 성공/실패를 바로 확인
- **사진 패널 소스 전환**: 왼쪽 사진 패널 상단 **[로컬 폴더 | MYBOX]** 탭으로 전환합니다.
- **폴더 탐색 및 캐시**: 폴더(먼저 표시)와 이미지 파일만 표시합니다. 암호 폴더·공유받은 폴더는 API로 접근할 수 없습니다. 썸네일은 원본 다운로드 후 로컬에서 `sips`로 생성합니다. 폴더를 열면 앞쪽 60장만 미리 받고 나머지는 고를 때 받으며, 일일 한도(429)나 인증 실패가 나면 자동 다운로드를 멈춥니다. 다운로드된 파일은 `userData/mybox-cache/`에 영구 캐시되어 앱을 껐다 켜도 다시 받지 않습니다.

#### 사용하는 MYBOX Open API 경로 (4개, 베이스 URL: `https://open-api.mybox.naver.com/v1`)

> 2단계 지시문에 적힌 경로입니다. 2026-11-25 실제 PAT로 4개 경로 모두 200 응답을 확인했습니다. 공식 문서(developers.mybox.naver.com) 텍스트와의 대조는 이 환경에서 사이트가 열리지 않아 하지 못했습니다(PLAN v0.7 Q9).
1. 루트 폴더 목록: `GET /v1/drive/resources` (`count`, `cursor`)
2. 하위 폴더 목록: `GET /v1/drive/folders/{folderId}/resources` (`count`, `cursor`)
3. 파일·폴더 1건 조회: `GET /v1/drive/resources/{resourceId}`
4. 파일 다운로드 (2단계): `GET /v1/drive/files/{fileId}/download` → `downloadUrl` 반환 (1회용, 10분 유효) → `GET <downloadUrl>`로 원본 바이트 다운로드

#### MYBOX 응답 구조 (2026-11-25 실제 PAT로 확인)
- 목록(`/drive/resources`, `/drive/folders/{id}/resources`): `{ resources: [...], fileCount, subFolderCount, responseMetaData: { nextCursor } }`
- 항목 필드: `resourceId`, `parentId`, `name`, `type`(`"folder"` / `"file"`), `size`, `isFavorite`, `isHidden`, `createdAt`, `modifiedAt`, `accessedAt`, `lastModifiedBy` (1건 조회에는 `category`가 더 있음)
- 수정 시각은 `modifiedAt`(날짜 문자열) → 캐시 키에 사용
- 다운로드(`/drive/files/{id}/download`): `{ downloadUrl, expiresIn: 600 }` (10분)
- 잘못된 토큰 → 401 → "MYBOX 연결이 안 돼요. 토큰을 다시 확인해줘"
- 앱의 `MyboxClient`로 연결 테스트·목록·하위 폴더·사진 다운로드·캐시 재사용까지 실제 서버에서 확인했다. `mybox.js`의 다른 후보 키는 형식 변경 대비용 예비다.
